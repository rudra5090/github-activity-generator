# Contributing

Thanks for contributing to GitHub Activity Generator.

## Development

1. Fork the repository or create a feature branch.
2. Keep changes focused and explain the motivation.
3. Run the test suite before opening a pull request:

```bash
python -m pytest -q
```

4. Update documentation when behavior changes.
5. Open a pull request using the repository template.

## Commit style

Use concise conventional-style messages such as `feat:`, `fix:`, `docs:`, `test:`, or `chore:`.

## Reporting bugs

Use the Bug Report issue template and include reproducible steps, expected behavior, environment details, and relevant logs.

## Security

Never commit passwords, API keys, tokens, private keys, or other secrets.
